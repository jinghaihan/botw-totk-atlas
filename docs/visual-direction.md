# Zelda Notes 视觉方向

整体采用 BOTW／TOTK 平板地图界面的视觉语言。地图为主体，Profile、筛选、详情和收集清单围绕地图组织。进入不同游戏的 Profile 时使用对应主题，共享布局和操作方式。

## 两套主题

BOTW 主题取希卡石板的深蓝底、青蓝高亮、浅米色文字和克制的古代纹样。TOTK 主题取普尔亚平板的深色面板、青绿高亮，以及金色和米白的辅助色。先建立可调整的颜色、边框、字距、阴影和动效变量，再用于所有组件。

两套主题共享信息层级。完成、未完成、未知、手动记录都提供图标或文字说明；选中点位、键盘焦点和悬停有独立反馈。

## 页面布局

- 桌面：地图占据主要空间；左侧管理 Profile、搜索和分类；右侧按需展开点位详情。
- 手机：地图保留主要视野；筛选、清单和详情使用可收起的底部抽屉，控制按钮留出足够点击区域。
- 神庙详情：并排呈现通关状态与宝箱领取状态，内部宝箱逐项展示奖励和完成来源。
- 导入：清楚显示文件、识别范围、目标 Profile 和进度变化，使用与地图一致的面板样式。
- 初次使用、无搜索结果、未知版本和损坏文件均有独立、可操作的空状态。

## 字体与动效

正文以中文可读性为先，标题增加游戏风格的字距和衬线气质。字体、图标和装饰素材随具体资源记录来源与授权。

使用短促的面板过渡、选中描边和轻量高亮。尊重减少动态效果设置，手机操作采用点按反馈，关键功能不依赖悬停。

## 第一轮预览

先交付可切换游戏主题的地图工作台布局，包含 Profile 入口、分类筛选、点位详情、神庙宝箱状态和手机抽屉。演示点位明确标识；真实底图和自动识别结果在对应功能接入后单独核对。
